# 🧠 Next Word Prediction using LSTM

An LSTM-based Next Word Prediction application built using **TensorFlow/Keras** and **Streamlit**.

The model takes a sequence of words as input and predicts the most likely next word based on patterns learned during training.

## 🚀 Features

- 🧠 LSTM-based sequence prediction
- ✍️ Interactive text input
- 🔮 Next-word prediction
- 📊 Top 5 likely word predictions with probabilities
- ⚡ Streamlit web interface
- 💾 Saved model and tokenizer for inference

## 🛠️ Tech Stack

- Python
- TensorFlow / Keras
- NumPy
- Streamlit
- Pickle
